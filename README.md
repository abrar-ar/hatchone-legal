# HatchOne — Legal

Public hosting for the HatchOne app's legal documents. Both the App Store and
Google Play require a publicly reachable privacy-policy URL, which is the only
reason this repository is public.

- [Terms of Use](https://abrar-ar.github.io/hatchone-legal/terms.html)
- [Privacy Policy](https://abrar-ar.github.io/hatchone-legal/privacy.html)

These pages are published copies. The canonical sources live in the private
HatchOne repository (`TERMS.md`, `PRIVACY.md`) — edit them there and re-publish,
so the app's in-app legal text and these pages cannot drift apart.
